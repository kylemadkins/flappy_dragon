# Flappy Dragon

A Flappy Bird clone written in Rust using [bracket-lib](https://github.com/amethyst/bracket-lib).

Fly the dragon through the gaps in the walls. Each wall you pass adds a point, and the gaps get smaller as your score goes up.

## Requirements

- Rust toolchain with support for the 2024 edition (Rust 1.85 or newer)

## Running

```sh
cargo run --release
```
